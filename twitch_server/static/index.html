Twitch-Scale End-to-End Media Pipeline

1. Contribution Ingest
Broadcaster pushes RTMP (Port 1935) or WHIP (HTTP POST SDP) to Nearest Edge PoP.
2. Real-Time Transcoder
FFmpeg/GPU Cluster transposes stream into Adaptive Bitrate ladder (1080p60, 720p, 480p).
3. Origin Shield & Packaging
Generates 1-second fMP4 chunks, LL-HLS playlists (.m3u8), and WebRTC WHEP relays.
4. Edge CDN & Player
CDN caches HLS fragments. Viewers fetch via Hls.js/WHEP with synchronized live chat.

Multi-Device Local Area Network (LAN) Setup

Mobile Web Gateway

Scan this QR code from your phone camera to open the Twitch server live on your device!

http://192.168.x.x:8000

OBS Studio / External App Setup

In OBS Studio under Settings -> Stream, select Custom... and set:

Server: rtmp://192.168.x.x:1935/live
Stream Key: test_stream

OBS will stream directly to your local Python backend on Port 1935.
